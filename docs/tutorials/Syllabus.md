# Syllabus

## 01-Learn-This-Project

Teaches how to build a "documentation expert" skill that reads a tool's live official docs instead of stale training data, plus the three-layer stack built on it: doc experts, cross-tool concept alignment, and automated config migration. Hands-on, the learner invokes and reads the layered skills (`claude-code-docs`, `concept-mapping`, `port-skill-generator`, the 12 `port-*` skills). After it, the learner can discover, verify, encode, and test a self-updating doc expert for any changing tool.
