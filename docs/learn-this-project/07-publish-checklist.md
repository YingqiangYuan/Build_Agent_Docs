## 5. Hostile-scan rules for Audit mode

Assume a reader scanning with "did this come from a tutorial?"

### File-pattern flags
| Pattern | Severity |
| :--- | :--- |
| `examples/` present | 🔴 HIGH |
| `docs/learn-this-project/` present | 🔴 HIGH |
| `.claude/skills/learn-this-project-{absorb,elevate,quiz,interview,demo,publish}/` present | 🔴 HIGH |
| any `**/README-cn.md` (or other `README-<locale>.md`) at any depth | 🔴 HIGH |
| `README-ORIGINAL.md` / `README-*.md` at root (other than `README.md`) | 🔴 HIGH |
| `docs/**/*-cn.md` | 🔴 HIGH |
| `tmp/` present with drafts/experiments | 🟡 MEDIUM |
| `.venv/`, `.idea/`, `*.egg-info/`, `.DS_Store` committed | 🔵 LOW |

### README phrase flags (scan the published README + the four `docs/0X`)
🔴 HIGH: `"this tutorial"`, `"course"`, `"lesson"`, `"as a student"`, `"we learned"`,
`"the mentor"`, `"in this project we"`, first-person-plural learning prose.

### Commit-message phrase flags
🟡 MEDIUM: same phrase set as above applied to `git log` subjects/bodies; also
`"from tutorial"`, `"course base"`, `"chore: setup"`-style non-descriptive messages.

### Git ref flags (`git tag --list`, `git branch --all`)
🔴 HIGH: tags/branches named `tutorial-base`, `from-course`, `v0-from-course`,
`original`, `from-tutorial`.

### Residual directory flags
🔴 HIGH: any `.claude/skills/learn-this-project-*/` **other than**
`lesson-smith-learn-this-project-meta/` (which is allowed).

### Hygiene flags
🔵 LOW: `.idea/`, `__pycache__/`, `.venv/`, `learn_build_agent_docs_skill.egg-info/`,
`.DS_Store` — ensure each is gitignored and untracked.

### Suspicious-symmetry flags (heuristic, not a hard rule)
🟡 MEDIUM: the 12 `port-*/SKILL.md` are template-generated and will share identical
structure — this is legitimate here (it's the point), but a hostile reader may read
it as machine-generated. Mitigation: the `port-skill-generator` + templates are
visible and explain the symmetry, so keep them in the repo. Likewise the three
doc-expert `SKILL.md`s share a procedure shape; that's by design and defensible.

### Severity legend
- 🔴 **HIGH** — fatal on detection; must be zero before publish is "clean".
- 🟡 **MEDIUM** — recoverable but visible; fix or consciously accept.
- 🔵 **LOW** — cosmetic; gitignore + untrack.
